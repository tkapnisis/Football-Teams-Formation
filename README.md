# Football Teams Formation (Python Terminal Edition)

This repository now contains a **terminal-only Python implementation** of the team management workflow.

## What is included

- `python_cli/team_manager.py` — function-based CLI application.
- `pootjeover_py.db` — local SQLite database created via `init-db` (not committed to git).
- `docs/python-terminal-start.md` — full command reference and usage guide.

## Quick start

```bash
python3 python_cli/team_manager.py --db pootjeover_py.db init-db
python3 python_cli/team_manager.py --db pootjeover_py.db list-players
```

Then follow the guide:

- [docs/python-terminal-start.md](docs/python-terminal-start.md)
